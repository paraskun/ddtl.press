# ddtl.press

Interactive explainers, built with [Astro](https://astro.build) and deployed on Vercel.

```sh
npm install
npm run dev      # http://localhost:4321
npm run verify   # type check + production build
```

Pages live in `src/content/pages/<slug>/index.mdx`. See [AGENTS.md](AGENTS.md) for how the site is organized.
